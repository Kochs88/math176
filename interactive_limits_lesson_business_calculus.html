Evaluating Limits Graphically and Numerically

In Business Calculus, limits help us understand how a quantity behaves as it gets close to a value. In this lesson, you will learn how to estimate limits using tables and graphs, identify when limits exist, and recognize common misconceptions.

Learning Goals

  • Define a limit using student-friendly language.
  • Estimate limits from graphs and tables.
  • Distinguish between a function value and a limit.
  • Recognize situations where a limit does not exist.

What Is a Limit?

A limit describes the value that a function is getting close to. The function may or may not actually equal that value.

When we write:

limx→2 f(x) = 4

we mean that as x gets closer and closer to 2, the y-values get closer and closer to 4.

Reading a Limit from a Table

Values approaching x = 2
x f(x)
1.93.8
1.993.98
2.014.02
2.14.2

Notice that the y-values are getting close to 4 from both sides. Therefore, the limit is 4.

The open circle shows that the function may not actually include the point. However, the graph still approaches that y-value.

Compare & Contrast

Limit Exists

A limit exists when the graph approaches the same y-value from the left and right side.

Even though there is an open circle, both sides approach the same value.

Limit Does Not Exist

A limit does not exist when the left side and right side approach different values.

The graph approaches different y-values from each side, so the limit does not exist.

Common Misconception

Students often think the limit and the function value must be the same. This is not always true.

Example:

  • The graph approaches y = 4.
  • But the actual function value at x = 2 might be undefined or equal to another number.

Limits describe what the graph is approaching, not necessarily the exact point shown.

Worked Example

Problem

Evaluate the following limit using the table and graph:

limx→3 (x + 2)

Step 1: Create a Table

x x + 2
2.94.9
2.994.99
3.015.01
3.15.1

The outputs are getting closer to 5.

Step 2: Analyze the Graph

As x approaches 3, the graph approaches 5.

Step 3: State the Limit

limx→3 (x + 2) = 5

The limit is 5 because the function values get closer and closer to 5 from both sides.

Self-Check Quiz

1. What does a limit describe?

2. If the left-hand and right-hand sides approach different values, what happens?

3. What is the limit of x + 1 as x approaches 2?

4. Can a limit exist even if the function is undefined at that point?
